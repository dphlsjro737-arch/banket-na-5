# banket-na5-site

Доработка сайта banket-na5.ru (банкетное направление ВЦ «ДонЭкспоцентр», Ростов-на-Дону) по ТЗ.

Сайт работает на **Tilda**. Блоки в `/blocks` — самодостаточный HTML/CSS/JS
(без React/сборки), рассчитаны на копирование целиком в HTML-блок Tilda
(T123 / Zero Block → «Вставка HTML»).

Полный текст технического задания — `tz/tz-banket-na5-v1.docx`.

## Как продолжать работу с Claude Code

1. Открой терминал в этой папке репозитория.
2. Запусти `claude`.
3. Скажи, какой блок делаем следующим (см. чек-лист ниже) — Claude Code
   создаст/отредактирует файл в `blocks/`.
4. Готовый файл целиком копируется в Tilda: код → в блок T123/Zero Block
   на нужной странице.

## Общие правила для всех блоков

- Чистый HTML + `<style>` + `<script>`, без внешних сборщиков.
- CSS-классы с префиксом `bn5-` и уникальным именем блока — чтобы не
  конфликтовать со стилями других блоков на той же странице.
- Картинки не хранятся в репозитории — грузятся напрямую в Tilda,
  в коде оставляются плейсхолдеры `src="СЮДА_ССЫЛКУ"`.
- Формы — по возможности штатные виджеты Tilda (интеграция с CRM,
  Метрикой и уведомлениями уже настроена), кастомные формы в Zero Block
  не используем без необходимости.
